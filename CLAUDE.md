# CLAUDE.md

Read and follow [AGENTS.md](AGENTS.md) as the source of repository-wide instructions.

## Claude-specific checklist

- Inspect the relevant Expo Router route and reusable components before changing code.
- Keep changes typed, cross-platform, accessible, and consistent with existing
  patterns.
- Do not invent APIs, environment variables, backend contracts, or production data.
- Run `npm run quality` after code or configuration changes.
- Summarize changed behavior and any remaining limitations without claiming checks
  that were not run.
